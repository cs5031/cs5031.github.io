# CS5031 — Advanced Algorithm Analysis

Website: https://cs5031.github.io/
Repository: https://github.com/cs5031/cs5031.github.io

## One-time setup
Upload `index.html`, `announcements.md`, and `instructor.md` to the repository root, commit to `main`, and enable GitHub Pages deployment from main/(root).

## Weekly PDF uploads (no code editing)
In the repository, create folders `materials/week01/` through `materials/week16/` as you need them. Use **Add file → Create new file** with a path like `materials/week01/README.md` if the folder does not exist.

Upload PDFs within a week folder (Add file → Upload files). File names containing `slide` appear under **Lecture Slides**; names containing `note` appear under **Detailed Notes**; other PDFs appear under **Additional Materials**. Examples: `slides-01.pdf`, `notes.pdf`, `practice.pdf`. The website fetches the public repository tree through GitHub's API; allow for cache delay and API limits.

## Edit without programming
- Update `announcements.md` in GitHub to post announcements.
- Update `instructor.md` for contact information and office hours.
- No index.html changes needed for normal PDF uploads.

## Important
PDFs in a public repository are public. Only upload files you have rights to distribute.
